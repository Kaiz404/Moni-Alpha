# Launch paperwork

This folder holds the data-handling records Moni needs before a store launch (issue #61). The public texts they back are the privacy policy and terms in [`../legal/`](../legal/).

| File | What it records |
| --- | --- |
| [`play-console.md`](play-console.md) | The answers for Google Play's Data safety form, the Financial features declaration and the permission declarations, each tied to a privacy policy section |
| [`processors-and-transfers.md`](processors-and-transfers.md) | Every processor, what it receives, where, under which agreement, and the PDPA s.129 record of cross-border transfers |
| [`breach-plan.md`](breach-plan.md) | Who does what in a data breach, the notice clocks, and the breach register |
| [`retention.md`](retention.md) | How long each kind of data is kept and what deletes it |

Facts in these files come from the code on 28 November 2026. A line marked **[CONFIRM]** is a fact the repo can't show; the owner fills it in. When the code changes what Moni collects, sends or keeps, update the privacy policy and these files in the same change.

A lawyer has not reviewed these records. The open questions for a lawyer are in [`../research/international-compliance-2026-11.md`](../research/international-compliance-2026-11.md#open-questions-for-a-lawyer).
